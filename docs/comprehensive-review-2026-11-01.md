# WordQuest 多角度审查与改进报告

审查日期：2026-11-01。对象：WordQuest 单词勇者，面向四六级的本地优先学习网站。

在线访问：https://runner-cpu.github.io/WordQuest/

## 结论

项目已经具备站内真题作答、词汇间隔复习、原创听力、情景表达和成就体系。当前主要短板从“有没有功能”转向“练完是否知道下一步、学习记录是否可信、复杂情况下能否保住输入”。本轮优先修复这些问题，并把仍需内容建设或更大产品设计的事项明确列为后续工作。

尤其要重视内容深度：实际扫描 10 套真题的 550 道客观题，当前结构化 `explanation` 数量为 0。能核对选项不等于能讲清原因。界面已明确缺少逐题解析，并支持错题筛选、选项对照和复盘笔记；这不替代人工核验的解析建设。

## 审查范围与证据

- 代码：应用壳、学习/统计/设置页、真题编辑、浏览器语音与录音、词书、奖励、备份、数据库与部署流程。
- 内容：逐套扫描 `public/exams/*/paper.json`，共 10 套、550 题、76 个听力材料组；62 组有起始时间；9 份写作参考和 9 份翻译参考；原卷录音约 159.6 MiB。
- 数据：首次/最近核对、重复练习、并发编辑、旧档案兼容、跨日复习统计。
- 界面：320、390、768、1440px 宽度及 844×390 横屏；星夜和晨光主题的报告与复盘页面。
- 工程：单元测试、真实浏览器端到端测试、类型/生产构建、依赖审计和 GitHub Pages 流程。
- 限制：没有声称完成真实 iOS/Android 设备矩阵、全部读屏软件验收、用户访谈或学习效果实验。以下产品判断不是通过率预测。

## 28 个观察角度

P1 表示影响数据可靠性或核心学习判断，P2 表示流程或体验缺口，P3 表示后续完善。这里按角度列出，相关问题可能共用同一项修复。

| 角度 | 不足与用户影响 | 优先级 | 本轮结果 / 后续工作 |
|---|---|---|---|
| 1. 四六级定位 | 统计以词卡为中心，仅做真题仍可能看到“没有学习数据” | P1 | **已修复**：独立的四/六级真题报告，词卡空态不再遮盖真题记录 |
| 2. 学习反馈深度 | 550 题有答案键，但没有结构化逐题解释；知道选项仍可能不理解 | P1 | **部分改善**：选项对照、缺失说明和证据复盘提示；逐题解析仍须编写、核验 |
| 3. 错题复盘效率 | 复盘把正确、未答、错题混列，需要逐个找 | P2 | **已改善**：全部/待订正/未答筛选，首个错题与下一道未答入口 |
| 4. 写作与翻译 | 空白分隔计数会把中文批注、数字算为英文词；自查方向不够明确 | P2 | **已改善**：英文词计数、按题干要求提示、内容/结构/语法/修订自查；未添加自动评分 |
| 5. 听力精听 | 76 组中 14 组缺少起始定位，且没有逐句对齐字幕 | P2 | 保留整段播放与已有分段定位；后续须人工对齐音频，不能猜测时间轴 |
| 6. 真题覆盖 | 目前仅 10 套第 1 套；不能代表所有卷别、难度和考试情境 | P2 | 如实保留高校整理版与卷别说明；后续增加经核验的其他卷别 |
| 7. 成绩可信度 | 首次作答和反复订正若混算，容易造成“已经掌握”的错觉 | P1 | **已改善**：报告只展示各题型首次正确/核对题数，最新错题单列；重复版本不叠加样本，不换算考试分数 |
| 8. 游戏激励 | 每日任务和成长奖励仍主要围绕词汇与原创练习，真题努力与成长反馈连接偏弱 | P2 | 本轮让真题过程可见；后续应奖励不同日期的有效复盘，先设计去重凭据，避免刷同一答案拿奖励 |
| 9. 复习调度 | “今天”按未来 24 小时统计，漏掉逾期词，且会把明天一部分算进今天 | P1 | **已修复**：按本地日历日分桶，今天包含逾期；跨午夜与夏令时边界使用日历运算 |
| 10. 图表表达 | 正确率低于 40% 被夹到同一高度；半年累计曲线从零开始却名为累计 | P2 | **已修复**：正确率完整 0–100%；补逐日数据文本；半年曲线补窗口前基数并明确窗口名称 |
| 11. 下一步建议 | 统计更多是展示数字，用户仍要自己找下一步 | P2 | **已改善**：提示待订正最多的题型，提供听力和阅读写译入口；这是练习建议，不是能力诊断 |
| 12. 新手引导 | 有目标级别与日期设置，但没有基于真实表现的入门能力诊断 | P3 | 维持短引导；后续用自愿、低压力的小样本诊断，避免首次进入就强制长测验 |
| 13. 信息结构 | 首页功能很多，新增功能继续堆在首页会影响主任务 | P2 | **控制增量**：新报告放统计页，自查按需展开，听力真题仍集中在听力页 |
| 14. 多标签数据安全 | 整份草稿保存可能把另一标签刚改的阅读或写作覆盖 | P1 | **已修复站内真题**：事务内逐题/逐字段合并；同一内容冲突时保留输入，显式选择本页或另一页 |
| 15. 手机切后台 | 650ms 自动保存窗口内切后台，浏览器可能暂停页面，输入仍待保存 | P1 | **已改善**：隐藏、pagehide 和卸载时触发保存，离开前保留未存提示；系统强杀仍不能保证落盘 |
| 16. 受限存储环境 | 词书索引、外观、挑战开关等直接访问 localStorage，可能使启动或设置失败 | P1 | **已修复**：可选偏好失败回退至当前会话内存；学习主数据仍用 IndexedDB；索引不是唯一数据源 |
| 17. 离线体验 | “完全离线可用”未区分已缓存与未下载内容 | P2 | **已澄清**：设置说明准确限定离线条件；自动测试验证无系统语音时播放原创录音及断网重听 |
| 18. 更新可靠性 | Service Worker 检查没有处理拒绝，轮询卸载后不清理 | P2 | **已修复**：清理轮询，后台/离线不检查，恢复联网检查，更新失败可重试 |
| 19. 键盘与语义 | 题号跳转只滚动，没有把键盘焦点放到答案；预填草稿标签识别不稳定 | P2 | **已修复**：跳转后聚焦输入，草稿使用独立显式标签，报告用语义表格与文本数据 |
| 20. 移动端阅读 | 部分设置输入使用 12–14px 字体，窄屏阅读和输入体验弱 | P2 | **已改善**：手机普通输入至少 16px、44px 高；保留大字号答题输入；冲突区可滚动和换行 |
| 21. 主题一致性 | 丰富主题增加对比度回归风险 | P2 | 已抽查 7 个固定主题：副文字在两个面板色上的最小令牌对比约 5.06:1；新增界面使用主题令牌，星夜/晨光实测。动态色相和全站所有状态不是本次全量验收 |
| 22. 性能与规模 | 统计页读取全部词典，只为已学词计算词频分布 | P2 | **已改善**：只批量读取已学词；保留页面分包。历史复习日志仍全量读取，长期大数据可进一步按时间索引聚合 |
| 23. 备份与同步 | 本地数据没有自动跨设备同步，媒体备份还有体积上限 | P2 | 保留并说明 JSON 迁移与合并规则；本轮不引入账号服务器。后续可补备份历史提醒、导出包完整性展示 |
| 24. 内容来源 | 高校公开资料不等于本项目原创或统一开放许可；当前缺少自动内容更新审校流程 | P2 | 保留来源、版本和哈希、整理版身份；后续内容入库继续单独核对来源与使用条件 |
| 25. 依赖安全 | 官方 npm 审计返回构建依赖链 2 项低、7 项中风险记录 | P2 | 生产依赖审计为 0；兼容修复预演变更为 0，未强制跨主版本替换 PWA 工具链。保留明确待办，不能称“全项目零漏洞” |
| 26. 发布质量 | 单元测试无法覆盖真实 DOM、浏览器音频、标签切换和 Service Worker | P1 | **已补齐关键流程**：6 项 Playwright 测试加入 Pages 发布前检查；失败保留截图和 trace |
| 27. 导航与可分享性 | 主导航为内存状态，不能直接分享某套练习链接，浏览器后退不等于应用导航 | P3 | 当前入口仍能直达对应学习页；深链接和历史栈需要统一路由设计，列入后续工作 |
| 28. 可维护性 | 旧自带资料编辑器与站内编辑器有重复保存逻辑，单文件 JSX 较密 | P2 | 报告计算、偏好回退、报告 UI 已拆分；本轮并发改进针对站内编辑器，旧附件编辑器统一重构仍待进行 |

## 本轮验证

- `npm test`：145 项通过，新增日历日复习、英文词计数、报告去重、并发草稿与受限存储测试。
- `npm run build`：TypeScript 与 Vite/PWA 生产构建通过；预缓存清单约 943 KiB，不包含全部真题录音。
- `npm run test:e2e`：6 项真实 Chromium 流程通过：真题报告/复盘导航、跨标签合并与冲突选择、停表条件下后台保存、禁用偏好存储的启动/设置、原创录音与离线重听、深浅主题和多尺寸布局。
- 对比度检查计算固定主题令牌；浏览器截图检查实际排版。没有声称完成 Safari 真机或学习效果实验。
- `npm audit --omit=dev --registry=https://registry.npmjs.org`：生产依赖没有已报告漏洞；开发依赖结果见上表。
- GitHub Actions 在发布前构建、运行单元测试、安装 Chromium 并运行端到端测试，失败阻止部署。

## 后续优先级

1. **内容解释**：先覆盖高频错题的证据句、干扰项原因和听力转述，再逐步覆盖全部题目；逐题人工校对，不用未经核验的生成内容冒充官方解析。
2. **真题精听**：补齐 14 组时间定位，规划逐句文本、AB 重听与听写；先保证对齐准确，再设计播放器。
3. **学习迁移**：真题错词/表达进入跨日回想队列；成就奖励独立回忆和隔日订正，保留首次成绩。
4. **产出反馈**：写译自查之后增加修订前后对照及可选教师反馈；自动反馈若引入，应明确局限与数据去向。
5. **长期工程**：旧编辑器统一、深链接、日志聚合、Safari 真机矩阵、构建依赖升级和备份提醒。

这些后续事项尚未实现，不包含在本轮已交付功能中。
