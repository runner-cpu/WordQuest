## 原创录音逐句时间轴

原创材料的录音路径由 `src/data/originalAudio.json` 按完整文本的内容摘要关联。`src/data/originalTimelines.json` 是独立的可编辑覆盖索引，当前 `overrides` 为空，表示尚未人工核定逐句边界。播放时读取媒体实际 `duration`，按句中词数分配近似起止点，界面应标明“估算定位”；加载前不编写任何精确总时长。

人工覆盖条目的形状如下；尖括号是待填字段，不能作为数据直接粘贴：

```text
"audio/original/<现有的20位内容摘要>.mp3": {
  "verified": true,
  "sourceNote": "核听人、核听日期、录音 sha256 与边界说明",
  "segments": [
    { "text": "与 splitListeningSentences 输出一致的第一句", "start": <实际起点秒数>, "end": <实际终点秒数> }
  ]
}
```

所有句子应完整、同序列出。允许句间静音空隙；不允许重叠、负数、无穷值或超过媒体时长。只有 `verified:true`、非空核听说明、句子文本与当前材料一致，并通过运行时媒体边界校验的条目才会替代估算。素材或文本改变后，应按新录音路径重新核听。
