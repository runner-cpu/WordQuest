# 四六级定位与专项完善报告

日期：2026-10-30。项目：WordQuest 单词勇者。

## 定位判断

原项目在词汇复习、像素角色、任务、印章与成就方面已有基础，但备考路径主要停留在词卡与原创听力。用户很容易看到游戏积累，却缺少完成阅读、写作、翻译后可保存、可订正、可继续的学习过程。针对四六级，最需要补的是题型训练与反馈证据。

本轮明确定位为 **CET-4 / CET-6 分项练习、复盘与词汇巩固**。情景冒险和表达工坊保留为日常运用加练；游戏阶段记录积累。专项正确率、任务完成数量、成就与阶段均不换算考试分数、CEFR 等级或过级概率。

## 新学习过程

### 阅读

4篇原创短文，每篇3题，练定位、推断、主旨、限定与论证理解。完整作答后保存首次成绩；解析逐题显示本人首次选择、参考答案、原文证据和中文说明。订正更新最新答案，不覆盖首次成绩。退出未交卷作答时提示继续完成或舍弃本轮。

推荐先找回未订正题目的证据。全部任务完成后推荐回看较早的证据与修订，不承诺尚未提供的独立重做流程。

### 写作与翻译

共8项原创任务。先写本人的英文，再主动打开行文提示、参考与修订说明，逐项核对3条具体自查。停笔后自动保存，也可手动保存或保存返回；关闭等待必要保存，失败时保留稿件与重试入口。编辑完成稿后，自查勾选归零，旧完成稿仍可展开比较。

字数统计帮助安排篇幅。四级写作参考120–180词，六级150–200词；翻译英文长度仅为本题参考。写作20词、翻译10词为保存自查的最小练习门槛，不代表完成考试任务或达到合格标准。这里没有自动阅卷，也不认证用户自评的正确性。

### 听力与游戏成长

听力保留原有练习与奖励，补本轮复盘；离开或重练会清除本轮逐题记录，页面明确提示该边界。新阅读、写译档案独立保存，不发放XP、金币，也不写入词汇FSRS或词汇准确率。原有冒险、印章、表达回想和成就继续服务日常学习。

## 数据与兼容

- 数据库升到schema 6，新增独立 `cetPractice` 表。
- 阅读首次答案、首次提交日期、最新答案分别保留；写译草稿、最近自查文本与勾选分开存储。
- 草稿依据编辑时刻处理，延迟的旧自动保存不会覆盖新稿；保存回执只确认对应修订。
- JSON备份包含专项档案；缺少新表的旧备份仍兼容。导入先校验，坏专项记录在任何表写入前拒绝。
- 合并分别比较草稿更新、最近提交、首次阅读记录的时间；尝试次数取较大快照，避免重复导入虚增。

主要实现见 `src/features/CetPrepHub.tsx`、`CetOutputExercise.tsx`，`src/core/cetPractice.ts`、`cetPlan.ts`，以及 `src/data/cetPractice.ts`。README与DESIGN已同步功能范围和视觉约定。

### 浏览器实际操作

使用独立的本地测试资料与合成测试作文。桌面1440×1000，手机视口390×844。

1. 四级阅读首次故意错1题，得到2/3；未交卷退出保护保留选择；只练1道错题并订正后，退出重开仍显示首次2/3、最新3/3。
2. 写作输入后直接关闭并重开，草稿恢复；132词样稿完成3项自查，修订后勾选清零，最新140词草稿和旧完成稿都保留。
3. 临时浏览六级保留四级目标；设置CET-6后主学词书同步六级核心词，再恢复CET-4与四级核心词。
4. 六级翻译输入一段测试译文，保存返回后重开，文字完整恢复；浅色纸墨风格下任务与中文原文可读。
5. 原创听力材料3完成2题，错1题；结果显示1/2、本人选择、正确答案、解析与原文入口，并明确离开后不保留逐题史。
6. 设置页显示2026-12-12“官方已公布”、其他未确认场次“预计”，附官方通知和核对日期。
7. 手机备考台与弹层测得横向滚动宽度等于可用宽度；阅读选项自然换行，底部行动可达。写作输入17px、专项主要说明16px。最终控制台无warn/error。

测试环境没有英语语音包，因此仅验收听力操作和回顾，未验证朗读音质。检查过程中发现Vite变换缓存仍返回旧设置组件，重启本项目预览服务后再验收；未影响其他项目服务。最终恢复星夜、像素、四级目标、今日备考台，清除临时视口覆盖。

## 仍需补齐的备考能力

| 后续优先项 | 当前实际边界 |
| --- | --- |
| 扩大题型覆盖 | 阅读仅有仔细阅读短练；尚缺选词填空、长篇匹配专项 |
| 建立完整考试节奏 | 尚无完整限时真题模拟；原创TTS材料不能替代正式题量与真题录音 |
| 提供可靠的产出反馈 | 写作、翻译采用参考与自查；尚无经验证的自动批改或教师反馈 |
| 增加复盘深度与内容量 | 听力逐题历史未持久保存；12项为起步内容库，需继续扩充并做难度校验 |
| 验证实际学习成效 | 尚无长期学习效果实验，不对提分、过级或能力等级作效果保证 |

本轮也未实测真实手机软键盘、屏幕阅读器、全部32种风格/配色组合或生产PWA断网流程；已完成的浏览器检查不应外推为这些测试已通过。
