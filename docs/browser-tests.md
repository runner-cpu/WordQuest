# 浏览器回归测试

单元测试检查计算和数据边界；Playwright 使用真实 Chromium 检查 DOM、IndexedDB、音频和 Service Worker。测试数据保存在独立浏览器上下文中，不使用个人浏览器资料。

```sh
npm ci
npx playwright install chromium
npm run build
npm test
npm run test:e2e
```

端到端测试会自动在 `127.0.0.1:4180` 启动构建预览服务。默认使用 Playwright 管理的 Chromium；已有兼容浏览器时，可用环境变量 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定其绝对路径。

当前学习闭环验收已通过 244 项单元测试和 23 项 Chromium 浏览器流程；各批交付记录见[学习闭环分批交付报告](./learning-loop-delivery-2026-11-12.md)。

覆盖的场景：

1. 没有词卡记录时仍显示真题报告；复盘筛选和键盘焦点定位。
2. 两个标签页并行编辑不同内容，合并保留；同字段冲突时选择本页或另一页。
3. 暂停页面计时器后切到后台，自动保存无需等待防抖计时器。
4. localStorage 读写被阻止时，仍能初始化、完成引导和打开设置。
5. 没有系统英语语音时，原创 MP3 真实播放；完整缓存后断网刷新重听。
6. 报告与复盘在手机、平板、桌面和横屏布局中的尺寸边界，星夜和晨光主题。
7. 结构化解析草稿与无解析回退、证据笔记、首次正确/订正/依据奖励分开去重，以及多标签页奖励和依据冲突。
8. 原创逐句循环、A/B、倍速与键盘；真题有完整定位的题组循环、切换停止，以及缺定位的明确说明。
9. 每日新词默认值、只有辨认记录的到期词进入产出题、新词同轮的独立产出，以及熟词暂停与恢复不删除历史。
10. 写译初稿和修订稿的文字、修改原因与各版自查在刷新后保留；修改文字使对应自查失效，手机原创专项保留已提交初稿快照。
11. 日期与自述基础可选或跳过，阶段建议说明原因并在刷新后保留；今日与统计按同一规则优先处理有解析覆盖的待订正题型。
12. 两个独立浏览器上下文用迁移码迁移双稿和奖励凭据，重复导入及导入后再次交卷均不加奖；复制被拒绝时全选完整迁移码；新浏览器首次统计说明可关闭并跨刷新保留。
13. localStorage 拒绝读写时，关闭统计说明后切页不重复；压缩能力不可用时明确保留 JSON 备份入口与键盘焦点。

迁移码的格式、字符及解压大小限制、损坏输入、旧版本兼容和存储拒绝后的内存回退另由单元测试覆盖。浏览器用例不把这些边界重复展开；测试范围也不表示所有记录量或设备均已逐一验证。

新词产出回合使用受控本地词书，单独阻止后台词书下载与 Service Worker，避免下载修复在读取测试词后替换其词频和释义；产出回合与一词结算断言完整保留。真实下载完整性由词书单测验证，Service Worker 离线音频由独立浏览器流程验证。

`test-results/` 和 `playwright-report/` 不提交仓库。失败时可查看截图、`error-context.md` 与 trace：

```sh
npx playwright show-trace test-results/<失败用例>/trace.zip
```

GitHub Pages 工作流在部署前运行这些检查。失败时停止发布，并上传浏览器测试证据，保留 7 天。

当前自动化仅使用 Chromium；这些测试不代表 Safari/Firefox 或真实手机系统的全面兼容性认证。
