# WordQuest 学习体验与游戏化完善

日期：2026-10-30。本轮重点是让用户在记忆、理解和运用之间切换，并且看见自己正在学会什么。

## 项目判断

项目已有 FSRS 复习、听力、像素战斗、任务和离线存储，基础循环完整。主要缺口是活动容易集中在重复刷词；成就缺少下一步引导；部分旧成就文案与判定不一致，奖励熬夜、错误或消费也偏离学习目标。

保留五栏导航和原有视觉世界，把游戏机制落在学习活动本身：自由选关、短回合目标、即时解释、最佳成绩、收藏进度和可追踪的成长目标。

## 已实现

| 学习者的问题 | 实际改动 |
| --- | --- |
| 背词缺少使用场景 | 校园、城市旅行、工作观点共 3 章 9 个原创情景，用英语理解规则、安排事情、判断信息、选择得体表达 |
| 不知道难度是否合适 | 每章 A2/B1/B2 三种难度，全部自由选择 |
| 答错后只知道错了 | 27 道挑战逐题展示正确答案与中文原因，随时回看原文 |
| 学完缺少可见收获 | 9 枚场景印章、27 星，每场 4 个关键词或表达 |
| 不知道追哪个成就 | 64 枚成就、六方向筛选、最近解锁、剩余进度、单项钉选，今日页同步展示 |
| 中断一天失去动力 | 扩展累计学习日期、跨日找回遗忘等目标，承认回归与恢复记忆的价值 |

情景流程为：选择故事 → 阅读四轮对话（50–110 英语词，中文主动展开）→ 语境理解、推断、得体表达各一道题 → 即时解析 → 交卷与回顾 → 重练或前往下个故事。结果页可以展开全部题目和解析。

单次至少答对 2/3 题获得印章；单次正确数决定本轮星级，地图保存最佳单次成绩，多轮不同正确题不会拼接成满星。每题首次答对获得 3 XP、1 金币，重练只补发尚未领过的题目奖励。每枚成就另有固定 20 金币。

情景成绩独立保存，不增加新词数、复习题数或词汇正确率，不推进 FSRS。当前是阅读与表达选择练习，不代表口语、听力或自由写作能力评测。

保留原 40 个成就 ID 与已有解锁记录，扩展到 64 枚，按坚持、词汇、复习、拼写、听力、运用组织。修正不可验证的听力速度条件，替换熬夜、故意答错、花光金币等目标。5 枚隐藏成就不通过推荐或进度提前泄露条件。

数据库升至 schema 4，增加 `adventures` 表。进度、奖励凭据、XP、金币和打卡同事务保存。JSON 导出、导入合并包含冒险记录，兼容旧备份；重复导入不补发奖励。成就追踪只是当前浏览器的展示偏好。

## 验证结果

- **62/62 自动测试通过**，覆盖原学习逻辑、内容结构、非法交卷、并发奖励、失败回滚、重玩补奖、备份兼容与幂等、成就条件、跨日恢复记忆和拼写指标。
- `npm run typecheck` 通过；最终 `npm run build` 通过，无构建警告。
- 浏览器完成：读故事、展开中文、对错解析、两星交卷、重玩满星、再次重玩、刷新持久化、成就筛选、钉选后今日同步、Escape 退出及保留答案继续练习。
- 真实奖励观察：首次 2/3 为 **+6 XP、+2 金币**；补齐至 3/3 为 **+3 XP、+1 金币**；再次 3/3 为 **+0 XP、+0 金币**。两枚冒险成就各奖励一次。
- 刷新后保留 **1/9 印章、3/27 星**。原单词学习仍为 **1 个新词、1 次复习、100% 词汇正确率**。
- 1440×1000 桌面、390×844 手机已检查；手机根页面宽 390，主内容宽与滚动宽同为 380，无横向溢出。检查星夜像素、晨光米白与护眼纸墨的阅读和操作。
- 浏览器最终错误/警告日志为空。手机底部行动区保留安全区域。

成就统计只读取轻量场景 ID 索引，对话与题目随冒险界面独立加载。最终入口 JS **139.60 kB / gzip 47.82 kB**，冒险独立块 **40.62 kB / gzip 16.53 kB**。构建生成 PWA 预缓存；本轮没有重新验证生产环境断网和真实手机设备。

## 后续学习玩法

九个情景是完整的首批内容，长期效果需要真实学习者反馈。后续优先观察是否读解析、是否切换学习活动、是否隔日回访、能否再次理解同类表达，再扩展内容。

建议继续增加围绕已学词汇的情景包、隔日换语境复现，以及有参考答案和解释的短句输出练习。继续把奖励绑定理解与回忆，避免积分替代学习。
