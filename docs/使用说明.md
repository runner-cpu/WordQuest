# 单词勇者 WordQuest 使用说明

**在线打开：[https://runner-cpu.github.io/WordQuest/](https://runner-cpu.github.io/WordQuest/)**

电脑和手机使用同一网址，在浏览器中即可开始。在线访问无需下载项目或启动电脑服务，两台设备也不必连接同一个 WiFi。首次使用请保持联网，让应用完成缓存并下载需要的词书。

## 电脑与手机如何操作

电脑宽屏在左侧切换页面，手机和窄屏在底部切换；五个入口名称相同：

| 入口 | 可以做什么 |
| --- | --- |
| 今日 | 完成词汇任务，进入四六级备考台、情景冒险和表达工坊 |
| 单词 | 选择与下载词书，通过地图练习单元，查找本地词条 |
| 听力 | 按四/六级和年份直接练真题听力，按需展开原创加练 |
| 统计 | 回顾学习数量、练习情况与积累 |
| 我的 | 查看角色、成就和外观，打开设置、修改目标或管理数据 |

布局会随窗口宽度切换。手机可收藏网址，也可通过浏览器的安装或“添加到主屏幕”功能创建入口；例如 iPhone Safari 的“分享 → 添加到主屏幕”。

## 第一次设置与下载词书

1. 打开网站，按引导选择四级或六级目标。考试日期和自述基础都可留空；也可输入计划日期、主动选择场次，以及选择「正在打基础 / 基础逐渐稳定 / 想练综合运用」。再设置每日新词量，并给吉祥物起名。
2. 选择后，应用会准备对应的核心词书；等待下载完成。四级核心词前 300 词随应用内置，完整词书仍需下载。
3. 在“单词”页查看词书的本地数量与下载状态。下载中断时，保持联网并重试“下载”或“重新下载”。
4. 回到“今日”，选择“开始今日学习”。每轮最多 24 个词，优先复习到期词，再补当天新词。新词先选择辨认，再增加拼写或听写；错题重练有上限，实际作答次数可能更多。新用户每日默认 10 个新词，可调整。

以后可到“我的 → 打开设置”修改目标级别、计划日期、自述基础、主学词书和每日新词量；日期和基础也可随时清空。查词和离线练习只使用已经下载到当前浏览器的内容。

## 看懂阶段与下一步建议

「今日 → 本周建议主攻」与「统计 → 下一步建议」使用同一规则，并说明推荐原因。计划日期按日历天计算：

| 距离所选计划日期 | 阶段建议 |
| --- | --- |
| 超过 90 天或未设置有效日期 | 基础积累；自述为「基础逐渐稳定」或「想练综合运用」时建议专项突破 |
| 46–90 天 | 专项突破 |
| 15–45 天 | 真题模考 |
| 0–14 天 | 考前冲刺 |

日期已过时会提醒更新计划日期，再按可选基础给出可继续的练习建议。有最近保存的待订正记录时，下一步优先从有解析覆盖的题型中选待订正最多的一项；没有解析覆盖时，提示手动对照原卷与答案。页面会分开说明解析覆盖、已核验和待人工核验草稿，不能把有解析当作全部内容已核验。

自述基础只是个人学习偏好，不是能力测评。跳过日期与基础仍可使用所有练习；阶段建议不会锁定入口，也不预测考试分数或过级概率。

## 用近年真题练习与保存草稿

在“听力”页练真题听力，在“今日 → 四六级备考台 → 阅读与写译真题”练阅读、写作和翻译。两个入口都可按级别和年份选卷。目前有 10 套高校整理第 1 套，共 550 道客观题（四级 6 套、六级 4 套），题目、录音与参考答案都在本站。

1. **点击“开始听力”或“开始练习”**：题目加载后直接作答，无需跳转高校网站或导入文件。已有档案显示“继续练习”；需要另开一轮时，展开该套“练习记录”。
2. **听读作答**：听力选一段材料，用播放器听录音（有可靠分段位置时可点击“播放本段”），点选选项；阅读在电脑上左右分栏，手机上材料与题目分别滚动。选词填空点击文章空格可定位答题框，长篇匹配可切换题号选择段落。
3. **完成写作与翻译**：在首页打开真题后，上方切换阅读、写作和翻译，原题和草稿在同一界面。需要时展开参考范文/译文；来源未提供的参考文本会注明。听力页只显示听力题与播放器。
4. **提交核对与订正**：点击“提交核对”并确认已答题数，系统使用内置参考答案核对。听力只核对 25 题，阅读只核对 30 题，分别保留首次和最近记录；两个入口共用同一套草稿。复盘页点击题号可回到原题订正。未答题不会算作已核对，不换算 710 分，写译不自动评分。
5. **缓存与续练**：在“复盘与缓存 → 本套资料与离线使用”点击缓存，等待进度完成，题目与完整录音即可在此设备离线使用。退出时自动保存并停止播放，返回对应试卷行点“继续练习”。

题目优先采用南京大学 eol 高校公开资料。2025 年 12 月六级资料缺少 10 题听力答案，未作为完整套卷上线。旧的自带资料档案保留原有 PDF、音频、答题卡与手动答案，不会套用另一版本答案。

“原创专项”另外提供阅读、写作和翻译短练，学习档案同样在本机保存。站内真题客观题按首次正确、订正正确与记录订正依据分别奖励；写译和原创专项只保留学习档案。换设备可用迁移码或 JSON 备份手动迁移作答记录；站内题目与录音在目标设备重新缓存即可，不占备份附件额度。

## 原创听力加练

听力页下方展开“原创加练”，选择“理解短练”或“句子练习”。4 组理解短练和 10 篇句子材料共配有 82 条内置英语合成录音，无需安装系统英语语音包。可整段或逐句播放、单句循环、手动设 A/B、按 0.75/1/1.25/1.5 倍速重听；空格播放/暂停、左右键换句，输入框中不拦截打字。退出或切材料会停止声音；默认不自动播放新材料。若之前关闭了发音，可就地点击“开启声音并播放”。

原创录音首次播放需要联网，完整播放并缓存后可离线重听。它们用于理解加练，仍明确标注合成语音。

## 让练习持续下去

- **情景冒险**：在“今日”进入校园、城市旅行或工作观点故事。9 个场景均可自由进入；每场 3 题，单次答对至少 2 题可收集印章，星星保留最佳单次成绩。
- **表达工坊**：换个语境主动补全短语。先尝试独立回想，需要时再展开提示；有到期内容时，一轮最多回想 5 句。
- **成就馆**：进入“我的 → 成就馆”，按方向或完成状态筛选 70 枚成就，追踪一个公开目标，在“今日”查看进度。隐藏成就在解锁后揭晓。
- **复盘**：在“统计”查看学习积累；结合答题记录和草稿变化安排下一步。角色等级与成就用于记录应用内积累，不是英语等级认证。

## 离线使用与版本更新

离线使用需要先在当前浏览器联网打开网站，让应用资源缓存完成，并下载词书、缓存所需真题：

| 内容 | 离线条件 |
| --- | --- |
| 网站界面、原创练习和情景内容 | 应用资源已成功缓存；仅收藏网址不代表缓存完成 |
| 词汇复习与本地查词 | 对应词书或单元已下载到当前浏览器 |
| 原创听力录音 | 所需录音已成功完整播放并缓存；无需系统英语语音包 |
| 站内真题与录音 | 在该套复盘页完成“缓存本套题目与录音”，再离线核对一次；录音不依赖系统英语语音包 |
| 旧档案的自带 PDF 与录音 | 文件已导入当前浏览器 |
| 尚未加载的套卷与未缓存录音 | 需联网，首次按需下载 |

准备离线前，可临时断网，确认常用页面、词书和本机文件能打开。首次未缓存就断网时，网站无法从远端加载。

出现“有新版本可用”时，先保存当前草稿，再点“更新”；也可选“稍后”继续当前学习。若已发布更新但没有提示，联网刷新页面后等待检查。不要直接清理站点数据来更新；确需清理前，先导出备份。

## 备份与电脑、手机之间迁移

学习记录、草稿、成就和导入文件保存在**当前浏览器本机**，不会自动跨设备或跨浏览器同步。同一个网址在电脑、手机中打开，仍各有一份本机数据；本地启动地址与在线网址的数据也彼此独立。

### 快速迁移已保存的记录

1. 在原设备进入“我的 → 打开设置 → 数据”，展开“快速迁移（迁移码）”，点“生成迁移码”。
2. 点“复制迁移码”，将完整内容传到目标设备。浏览器拒绝复制时，点“全选迁移码”后使用系统复制操作。
3. 在目标设备打开同一数据区域，将完整内容放入“粘贴迁移码”，点“导入迁移码并合并”。失败时输入会保留，可检查后重试。
4. 合并成功后检查作答记录、初稿与修订稿、成就和设置，再重新下载需要的词书、缓存录音。重复导入同一记录不会再次发放奖励。

迁移码在本机生成与合并，不会后台上传，也不会自动同步。它随记录量增长，不是固定长度短码；省略全部词条正文、录音和文档附件，保留学习记录、草稿、设置与奖励凭据。自建词条正文和自带 PDF、录音应另用 JSON 完整备份保留。浏览器不支持压缩、迁移码超过 2,097,152 字符或解压后数据超过 8 MiB 时，请使用“转到 JSON 备份”。

### JSON 完整备份与恢复

1. 在原设备进入“我的 → 打开设置 → 数据”，选择“导出数据备份（JSON）”，确认文件已保存。
2. 将该 JSON 文件传到目标设备。打开上方在线网址，进入同一数据区域，选择“导入备份并合并”。
3. 合并完成后，检查学习记录、成就、真题档案、写译草稿和附件是否齐全，再继续学习。

当前 JSON 备份为 schema 12，包含词条正文、学习记录、可选计划偏好、逐词难度元数据、外观、任务、情景和表达进度，以及四六级专项、真题档案和导入文件。音频与文档附件合计超过 100MB 时，导出会跳过超额附件并提示；档案仍保留，请另外保存这些原始 PDF 和录音，在目标设备需要时重新导入。

迁移码与 JSON 使用相同合并规则：保留已有记录，按日志和各类档案的时间合并；奖励凭据去重，导入不补发奖励。新设备尚未学习时恢复备份中的学习与外观设置；已有学习进度时保留本机设置，设备标识始终保持本机值。旧备份缺少新增字段时仍可导入。

建议定期备份，尤其是在换设备、更换浏览器或清理站点数据之前。浏览器持久存储许可可以减少自动清理风险，不能替代备份。

## 可选：在自己电脑上本地运行

普通学习用户直接访问在线网址即可。希望本地运行项目时，按 [README 的本地运行步骤](../README.md#可选本地运行)启动服务。

仅本地方案需要让手机和运行服务的电脑连接同一个 WiFi，再打开启动器显示的局域网地址。在线网站没有这一限制。本地服务关闭后，局域网地址停止提供服务；学习记录可用迁移码或 JSON 备份手动迁移。


## 真题报告与更快复盘

在「统计」查看当前目标级别的真题报告，按听力、选词填空、长篇匹配、仔细阅读分别显示已答题数、首次核对正确题数和最近待订正题数。即使尚未开始词卡学习，真题记录也会显示。每套同版本试卷只取最近有作答的档案，重复开卷不叠加样本。

词卡累计、词卡报告、四六级练习报告以及导出的学习报告海报均标明「本机数据」，只包含当前浏览器保存的记录。首次打开统计页会显示「当前数据来自本浏览器，跨设备请使用迁移」，点「知道了」即可关闭，报告仍可直接使用。新浏览器仍会显示这项说明；关闭状态不随迁移码或 JSON 备份传递。浏览器拒绝保存关闭状态时，本次使用仍会记住，切页不会反复显示。

在真题的「复盘与缓存」中，可筛选「待订正」或「未答」，也可以直接进入第一个错题、下一道未答题。订正时建议先关掉参考答案，找到文章或录音证据再核对。有结构化解析的错题会就地展开；目前仅 2026 年 6 月四级第 1 套仔细阅读 46–55 提供待人工核验草稿，其他题显示“本题暂无结构化解析，仅提供参考答案”。证据句可加入复盘笔记，订正时也可单独记录原文依据。

写作和翻译显示英文词数，具体要求以题干为准。切换「初稿 / 修订稿」保留两版，选择修改原因并逐项自查。修改文字会清除这一版自查；对照参考可点击句子或手动选择段落。定位只按段落顺序，不作自动评分。原创专项的“完成自查”保存初稿完成快照；修订稿单独保存，草稿数量不等于完成自查。

词卡报告的「今天」复习量包含逾期任务；正确率曲线显示完整 0–100% 范围，也可展开逐日文字数据。

## 同时打开多个页面时

站内真题会合并不同题目、不同草稿字段的修改。如果两个页面改了同一道题或同一份作文，会暂停自动保存并保留输入。选择「保留本页修改并保存」会采用本页修改；选择「放弃本页修改，载入另一页」会载入另一份已保存内容。

页面切到后台时会尝试立即保存。系统强行关闭应用可能使保存来不及完成，离开前请留意「已保存到本机」。这些机制不等于跨设备同步；换设备请使用迁移码或 JSON 备份。


## 熟词与主动产出

词书下载后，可在对应词书卡片打开“快速标记熟词”，搜索英文或释义，先回想再展开释义，标为熟词后暂停进入练习队列。历史记录保留，点击“恢复练习”重新加入。这个入口用于自我安排，不是权威词汇量测验。

到期词没有准确拼写或听写记录时，会优先安排产出题。统计中的“掌握”要求 FSRS 复习间隔达到 21 天且有至少一次准确产出；选择题正确率、熟词标记均不能直接替代。统计另列产出覆盖，旧记录以已有日志重建。

## 订正奖励如何计算

站内真题客观题分三类一次性记录：首次正确每题 2 XP/1 金币，原错题订正正确 3 XP/1 金币，记录订正依据 1 XP/1 金币。结算分别显示来源，不要求连续打卡。依据奖励表示你留下了订正记录，不自动判定文字质量；自带资料的自定义答案不触发此奖励。同一来源、题目版本和题号各类只领一次，刷新、重复提交和导入不会再次领取。

真题中 60 组听力已有完整起止区间，可直接循环本题组；2 组只有起点，14 组尚无起点，后两类用完整录音和手动 A/B。原创全文的逐句时间轴为机器估算、待校对，参考文本标明“精听参考”，不是考试字幕。
