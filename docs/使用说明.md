# 单词勇者 WordQuest 使用说明

**在线打开：[https://runner-cpu.github.io/WordQuest/](https://runner-cpu.github.io/WordQuest/)**

电脑和手机使用同一网址，在浏览器中即可开始。在线访问无需下载项目或启动电脑服务，两台设备也不必连接同一个 WiFi。首次使用请保持联网，让应用完成缓存并下载需要的词书。

## 电脑与手机如何操作

电脑宽屏在左侧切换页面，手机和窄屏在底部切换；五个入口名称相同：

| 入口 | 可以做什么 |
| --- | --- |
| 今日 | 完成词汇任务，进入四六级备考台、情景冒险和表达工坊 |
| 单词 | 选择与下载词书，通过地图练习单元，查找本地词条 |
| 听力 | 按四/六级和年份直接练真题听力，按需展开原创加练 |
| 统计 | 回顾学习数量、练习情况与积累 |
| 我的 | 查看角色、成就和外观，打开设置、修改目标或管理数据 |

布局会随窗口宽度切换。手机可收藏网址，也可通过浏览器的安装或“添加到主屏幕”功能创建入口；例如 iPhone Safari 的“分享 → 添加到主屏幕”。

## 第一次设置与下载词书

1. 打开网站，按引导选择四级或六级目标、计划考试场次及日期，设置每日新词量，并给吉祥物起名。
2. 选择后，应用会准备对应的核心词书；等待下载完成。四级核心词前 300 词随应用内置，完整词书仍需下载。
3. 在“单词”页查看词书的本地数量与下载状态。下载中断时，保持联网并重试“下载”或“重新下载”。
4. 回到“今日”，选择“开始今日学习”。每轮最多 24 题，优先复习到期词，再补当天新词；本轮答错词会再练一次。

以后可到“我的 → 打开设置”修改目标级别、计划日期、主学词书和每日新词量。查词和离线练习只使用已经下载到当前浏览器的内容。

## 用近年真题练习与保存草稿

在“听力”页练真题听力，在“今日 → 四六级备考台 → 阅读与写译真题”练阅读、写作和翻译。两个入口都可按级别和年份选卷。目前有 10 套高校整理第 1 套，共 550 道客观题（四级 6 套、六级 4 套），题目、录音与参考答案都在本站。

1. **点击“开始听力”或“开始练习”**：题目加载后直接作答，无需跳转高校网站或导入文件。已有档案显示“继续练习”；需要另开一轮时，展开该套“练习记录”。
2. **听读作答**：听力选一段材料，用播放器听录音（有可靠分段位置时可点击“播放本段”），点选选项；阅读在电脑上左右分栏，手机上材料与题目分别滚动。选词填空点击文章空格可定位答题框，长篇匹配可切换题号选择段落。
3. **完成写作与翻译**：在首页打开真题后，上方切换阅读、写作和翻译，原题和草稿在同一界面。需要时展开参考范文/译文；来源未提供的参考文本会注明。听力页只显示听力题与播放器。
4. **提交核对与订正**：点击“提交核对”并确认已答题数，系统使用内置参考答案核对。听力只核对 25 题，阅读只核对 30 题，分别保留首次和最近记录；两个入口共用同一套草稿。复盘页点击题号可回到原题订正。未答题不会算作已核对，不换算 710 分，写译不自动评分。
5. **缓存与续练**：在“复盘与缓存 → 本套资料与离线使用”点击缓存，等待进度完成，题目与完整录音即可在此设备离线使用。退出时自动保存并停止播放，返回对应试卷行点“继续练习”。

题目优先采用南京大学 eol 高校公开资料。2025 年 12 月六级资料缺少 10 题听力答案，未作为完整套卷上线。旧的自带资料档案保留原有 PDF、音频、答题卡与手动答案，不会套用另一版本答案。

“原创专项”另外提供阅读、写作和翻译短练，学习档案同样在本机保存。真题和原创专项不发放经验或金币。换设备请使用 JSON 备份迁移作答记录；站内题目与录音在目标设备重新缓存即可，不占备份附件额度。

## 原创听力加练

听力页下方展开“原创加练”，选择“理解短练”或“句子练习”。4 组理解短练和 10 篇句子材料共配有 82 条内置英语合成录音，无需安装系统英语语音包。点击播放后可停止、调速重听，退出练习会停止声音；默认不自动播放新材料。若之前关闭了发音，可就地点击“开启声音并播放”。

原创录音首次播放需要联网，完整播放并缓存后可离线重听。它们用于理解加练，仍明确标注合成语音。

## 让练习持续下去

- **情景冒险**：在“今日”进入校园、城市旅行或工作观点故事。9 个场景均可自由进入；每场 3 题，单次答对至少 2 题可收集印章，星星保留最佳单次成绩。
- **表达工坊**：换个语境主动补全短语。先尝试独立回想，需要时再展开提示；有到期内容时，一轮最多回想 5 句。
- **成就馆**：进入“我的 → 成就馆”，按方向或完成状态筛选 68 枚成就，追踪一个公开目标，在“今日”查看进度。隐藏成就在解锁后揭晓。
- **复盘**：在“统计”查看学习积累；结合答题记录和草稿变化安排下一步。角色等级与成就用于记录应用内积累，不是英语等级认证。

## 离线使用与版本更新

离线使用需要先在当前浏览器联网打开网站，让应用资源缓存完成，并下载词书、缓存所需真题：

| 内容 | 离线条件 |
| --- | --- |
| 网站界面、原创练习和情景内容 | 应用资源已成功缓存；仅收藏网址不代表缓存完成 |
| 词汇复习与本地查词 | 对应词书或单元已下载到当前浏览器 |
| 原创听力录音 | 所需录音已成功完整播放并缓存；无需系统英语语音包 |
| 站内真题与录音 | 在该套复盘页完成“缓存本套题目与录音”，再离线核对一次；录音不依赖系统英语语音包 |
| 旧档案的自带 PDF 与录音 | 文件已导入当前浏览器 |
| 尚未加载的套卷与未缓存录音 | 需联网，首次按需下载 |

准备离线前，可临时断网，确认常用页面、词书和本机文件能打开。首次未缓存就断网时，网站无法从远端加载。

出现“有新版本可用”时，先保存当前草稿，再点“更新”；也可选“稍后”继续当前学习。若已发布更新但没有提示，联网刷新页面后等待检查。不要直接清理站点数据来更新；确需清理前，先导出备份。

## 备份与电脑、手机之间迁移

学习记录、草稿、成就和导入文件保存在**当前浏览器本机**，不会自动跨设备或跨浏览器同步。同一个网址在电脑、手机中打开，仍各有一份本机数据；本地启动地址与在线网址的数据也彼此独立。

1. 在原设备进入“我的 → 打开设置 → 数据”，选择“导出数据备份（JSON）”，确认文件已保存。
2. 将该 JSON 文件传到目标设备。打开上方在线网址，进入同一数据区域，选择“导入备份并合并”。
3. 合并完成后，检查学习记录、成就、真题档案、写译草稿和附件是否齐全，再继续学习。

备份包含学习记录、设置、外观、任务、情景和表达进度，以及四六级专项、真题档案和导入文件。音频与文档附件合计超过 100MB 时，导出会跳过超额附件并提示；档案仍保留，请另外保存这些原始 PDF 和录音，在目标设备需要时重新导入。

建议定期备份，尤其是在换设备、更换浏览器或清理站点数据之前。浏览器持久存储许可可以减少自动清理风险，不能替代备份。

## 可选：在自己电脑上本地运行

普通学习用户直接访问在线网址即可。希望本地运行项目时，按 [README 的本地运行步骤](../README.md#可选本地运行)启动服务。

仅本地方案需要让手机和运行服务的电脑连接同一个 WiFi，再打开启动器显示的局域网地址。在线网站没有这一限制。本地服务关闭后，局域网地址停止提供服务；需要迁移学习记录时，仍使用 JSON 备份。
