## 学习体验

- 听力播放器保持挂载，切换题型可继续播放。可按题组浏览选项，来源有可靠时间标记时提供本段定位。
- 电脑材料与答题区左右分栏、分别滚动。手机上下布局，两区各自滚动；短屏横向布局压缩导航，保留正文空间。
- 原生单选框直接点选，支持键盘操作、清除本题选择、55 题复盘定位。长篇匹配只提供原文实际段落；选词填空标示其他空已使用的单词。
- 提交前明确已答、未答数，按内置答案核对已答题目。首次与最近结果独立保留；可开启参考答案返回原题订正。
- 写作、翻译原题与草稿同时呈现，参考内容按需展开。草稿与复盘笔记自动保存；存储失败有重试，未保存时保护离页。
- 旧自带 PDF、音频和手动答案档案继续使用原界面，不把不同整理版本混用。新档案保留题目修订号，备份合并拒绝版本冲突。

## 内容与下载

`npm run ingest:cet` 读取来源页实际下载链接，将公开 HTML 解析成文本题目，将 PDF 与录音保存至 `public/exams/`。`src/data/cetReadyPapers.json` 只包含索引和修订号，题目和音频在进入套卷时按需加载，首页不下载所有录音。

对照来源原卷恢复了 2026-06 两级及 2025-12 四级网页中被截断的匹配题，并去掉错拼到末段的文本；2025-12 四级第一篇阅读和第二篇起点依据原卷修正。选项中混入的 Section B/C 指示、翻译原文后混入的来源页脚已清理。显式修正记录见 `scripts/cet-paper-corrections.json`，没有用原创题补成真题。2026-06 四级与 2024-12 四级来源页使用均分录音时长的估算分段，导入时舍弃这些估算位置，保留完整播放器和从头播放，避免错误跳段。

每套 JSON 保留原始来源 URL、PDF/音频 SHA-256 与大小。加载器核验 JSON 大小、修订号、55 题题号、选项、参考答案、材料与资产路径。已提供的客观题答案已与来源答案 PDF 核对。

「复盘与缓存 → 本套资料与离线使用」支持下载完整录音并显示进度。仅通过字节数和 SHA-256 检查后将完整 200 响应写入缓存，离线播放支持 Range 请求。无需预缓存所有大文件；浏览器可能回收缓存，准备离线前应实际断网确认。学习记录存于 IndexedDB，备份迁移记录后，在目标设备重新缓存公共资料即可。

没有提供整卷计时、写译自动评分、710 分换算或成绩认证。第三方内容权利与用途见 [第三方声明](../THIRD-PARTY-NOTICES.md)。
