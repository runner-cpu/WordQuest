# 单词勇者 WordQuest

项目介绍：[中文介绍与英文简介](./docs/WordQuest-项目介绍.md) · [PDF 文档](./output/pdf/WordQuest-项目介绍.pdf)

面向 **CET-4 / CET-6 分项练习、复盘与词汇巩固**的离线优先学习应用。把词汇复习、听力短练、阅读找证据和写译修订连接起来，让每次学习都有明确任务和可回看的记录。

今日页先完成词汇任务，再进入四六级备考台，默认从近年高校公开真题资料开始，结合原卷、录音、答题卡和写译草稿练习；原创专项用于短时加练。情景冒险与表达工坊作为日常运用加练，提供故事、印章和跨日回想。像素角色与成就记录学习积累；应用内阶段、正确率和完成数量不换算考试分数、CEFR 等级或过级概率。

## 怎么用

### GitHub Pages 部署

仓库的 `.github/workflows/pages.yml` 在推送到 `main` 或手动运行时，依次执行依赖安装、生产构建和测试，再将 `dist` 发布到 GitHub Pages。构建先生成离线尝鲜词包，随后测试，支持干净检出后的 CI 环境。

首次发布时在仓库的 **Settings → Pages → Build and deployment** 将 Source 设为 **GitHub Actions**。项目使用相对资源路径，适配 `https://runner-cpu.github.io/WordQuest/`。后续推送到 `main` 会自动更新；已安装 PWA 的用户可在出现新版本提示后更新。

### 第一步：启动

**Windows**：双击 `启动应用.bat`

**macOS / Linux**：先执行一次 `chmod +x 启动应用.command`，之后双击 `启动应用.command`

首次运行会自动装依赖并构建（约 1-2 分钟），之后每次启动只需 1 秒。浏览器会自动打开应用。

关闭那个命令行窗口即停止服务。

### 第二步：第一次打开

1. **直接进入引导**（不用先找到入口），选考试类型（四级/六级），再从**考试场次列表**里挑一次
2. **四级核心词的前 300 词已内置**，首次进入先读取本地资料，完整词库在后台补齐；其他词书需先下载，之后可离线学习
3. 选择目标日期：**2026 年 12 月 12 日笔试为官方已公布日期**，界面提供来源；其他未确认场次标为预计，自定义日期标为个人计划。倒计时按你保存的日期计算
4. 选完会**自动下载对应词书**
5. 回到今日页，点「开始今日学习」

每周一首次打开可查看「本周战报」，比较新词、复习、精听和词汇正确率。修改备考目标级别时，默认主学词书同步为对应级别的核心词；已有学习记录保留。已公布日期来源见[教育部教育考试院报名通知](https://www.neea.edu.cn/html1/report/2609/1-1.htm)，核对日期为 2026-10-30；预计日期仍应以之后的官方通知为准。

### 第三步：每天用

- **今日页**点「开始今日学习」，每轮最多 24 题，复习优先，剩余名额给当天尚未完成的新词目标
- 答错的词会在本轮末尾重练一次
- 答完看结算，点「今日达成」退出
- 想加练就再点「再来一轮」，剩余的到期复习会继续排；达到每日新词目标后，不会因再开一轮而重复领取整天的新词额度
- 词汇任务后打开「四六级备考台」，默认进入「近年真题」：按年份和级别选资料，从高校原站看题、听录音，或导入本机文件；在练习档案里填写答题卡、写译草稿和复盘。也可切换「原创专项」做短练。词汇目标完成后，主按钮会带你选择一项备考训练
- 想看看英语怎么用，打开今日页的「英语情景冒险」，读一段故事、完成 3 道挑战，再把印章收入冒险护照
- 想把表达带走，在「表达工坊」补全新情境中的短语；有到期内容时，回想队列每轮最多 5 句，也可以选喜欢的场景自由练习
- 在「我的 → 成就馆」按学习方向筛选目标，追踪一枚公开成就；今日页会显示对应进度，也可改为自动推荐

### 电脑与手机

- **电脑**：左侧固定侧边栏导航，内容区多列排布，顶栏常驻主题切换与设置
- **手机**：底部五栏导航，单列布局，顶栏图标收成纯图标

窗口变窄会自动切换，不需要装两个版本。

### 手机上用

启动后命令行会打印一行「手机访问 http://192.168.x.x:4173」，手机连同一个 WiFi 直接打开这个地址即可。

iPhone 上建议用 Safari 打开后点分享 → 添加到主屏幕，并定期导出备份。长期未访问或清理浏览器时，本地数据仍有丢失风险。

### 数据安全

- 学习记录存在浏览器本地（IndexedDB），不上传任何服务器
- **启动时申请持久存储许可**（`navigator.storage.persist`）：获得许可后系统不会在磁盘紧张时自动清退数据；设置页可查看当前许可状态与用量/配额
- 「设置 → 数据 → 导出数据备份」可存一份 schema 7 JSON 到本地，包含学习记录、词库归属、个人设置、外观库存、每日任务、冒险进度、表达练习调度与奖励日期凭据、CET 专项和真题档案，以及导入的 PDF、试卷包与音频（音频、文档合计超 100MB 时跳过超额附件并提示；档案仍保留）
- 「设置 → 数据 → 导入备份并合并」按 id 合并复习日志、成就、真题档案、试卷包与附件，由日志重建 FSRS 状态；旧版仅有统计的数据也会保留。外观取并集，金币等余额取较大值，重复导入不会重复加奖
- 新设备尚未学习时恢复备份中的学习与外观设置；已有学习进度时保留本机设置。设备标识保持本机值
- 冒险按场景合并最佳成绩与首次答对题目集合，保留护照进度；重复导入或重玩已领奖题目不会再次发奖。旧备份缺少冒险数据时仍可导入
- 表达记录按题目合并：独立完成日与奖励日取并集，调度采用日期较新的一方，同日冲突保留更早的到期时间与较低阶段；导入不补发奖励。旧备份没有表达记录仍可导入
- CET 档案包含阅读首次答案、最新订正，及写译草稿、最近完成自查的文本和勾选。草稿、最近提交、首次阅读答案分别按各自时间合并，尝试次数取较大值；旧备份没有 `cetPractice` 仍可导入
- 真题档案 `cetPapers` 包含来源、卷别、55 题选项与录入的参考答案、写作草稿、译文、笔记和首次/最近核对快照。备份分别合并草稿、首次与最近提交；缺少附件字节的备份不会删除本机唯一文件。旧备份没有真题档案仍可导入
- 启动和各页面都有错误恢复入口；战斗每题作答实时落库，页面加载失败可重试

### 常见问题

**改了代码但界面没变**：Service Worker 缓存了旧版本。应用会在启动时检查更新并弹出「有新版本可用」，点更新即可。若仍不生效，在浏览器开发者工具里 Application → Service Workers 勾选 Update on reload，或清空站点数据。

**手机上打不开局域网地址**：确认手机与电脑连的是同一个 WiFi，且电脑防火墙允许 Node.js 接收连接。

**词库下载失败**：应用会在启动时自动重试并补齐缺失单元。也可以到「单词」页手动点「下载」。

**想重置所有数据**：浏览器开发者工具 → Application → Storage → Clear site data。注意这会清空学习记录，建议先导出备份。

## 已实现的功能

### 核心学习循环（M0）

- **FSRS 间隔重复**（ts-fsrs v5，官方默认参数，四档评级）
- **五种题型**：看词选义 / 看义选词 / 拼写 / 听音辨义 / 听音拼写
  - 拼写类占复习题量 50%（12 题样本中 6 题为拼写类，符合方案 §5.1 的「≥50%」要求）
  - 新词首轮只出四选一，降低首次接触的挫败感
- **自动评级**：由正确性与用时推导，答错→Again、秒答→Easy、擦边一个字母→Hard
  - 想自己掌控可点「想手动评级」切换四档
- **答错重排**：错词在本轮末尾重练一次（同一词最多重排一次，不会无限循环）
- **全程键盘可操作**：空格朗读、回车继续

### 四六级备考台：近年真题与专项复盘

入口位于今日词汇任务之后、日常情景冒险之前，保留现有五栏导航。默认跟随已设置的四级或六级目标，也可临时浏览另一等级；浏览切换不会改动保存的备考目标。考试结构说明引用[教育部教育考试院笔试说明](https://cet.neea.edu.cn/html1/report/16123/177-1.htm)。

**默认进入近年真题资料目录**。收录 2023 年 6 月至 2026 年 6 月的 7 个场次，四级、六级各 7 条，共 **14 条高校公开资料入口**，每期采用来源所称第 1 套。南京大学 eol 平台提供 2024–2026 年资料；2023 年资料来自新疆第二医学院语言文化部，附件需在学校网页填写验证码。核对日期为 2026-10-30，尚未举行的 2026 年 12 月不在目录中。高校托管和整理版本不等于考试院官方原卷或官方答案，同月份不同整理者的套号也可能不同，练习前应同时核对题目与答案。

- **原卷与录音**：从来源页打开 PDF、答案解析和原始录音；也可将原卷 PDF、答案 PDF、录音分别导入本机后离线使用。单个 PDF 不超过 30MB，单个音频不超过 60MB；文件类型、大小与文件头都会检查。目录保存来源和附件元数据，项目没有内置这 14 份整卷正文
- **55 题答题卡**：按听力 1–25、选词填空 26–35、长篇匹配 36–45、仔细阅读 46–55 分组。用户录入与原卷相符的参考答案后核对，只统计已经作答且有参考答案的题目；缺少参考答案的题目不会当作已经核对
- **先保留首次，再做订正**：首次与最近核对各保存独立的选项和参考答案快照，后续修改不会覆盖首次表现。卷别、选项、写作草稿、译文和复盘笔记可自动或手动保存，返回后接着练
- **结果边界明确**：核对依据用户录入的参考答案，应用不自动认证答案真实性、不从 PDF 识题、不自动评阅写译、不换算 710 分或过级概率。真题档案不发放 XP、金币，也不改变词汇 FSRS

来源逐条核对记录见 [近年真题资料来源](./output/verification/recent-cet-sources.md)，实现范围与验收见 [近年真题完善报告](./docs/recent-cet-papers-2026-10-30.md)。远端资料需联网，链接可用性以本次核对为准；已导入的本机文件随本机档案保存。

内置 **12 项原创专项练习**：两级各 6 项，合计阅读、写作、翻译各 4 项。阅读侧重仔细阅读中的定位、推断和论证理解，篇幅与题量均为短练，尚未覆盖选词填空、长篇匹配或完整模拟卷。

- **阅读先完整作答，再找证据**：每篇 4 段、3 道四选一；交卷成功后保存首次答案与最近答案，逐题显示原文证据和中文解析。可以只练最新仍错的题，订正不会覆盖首次表现；返回或刷新后可继续复盘
- **写作与翻译先起草，再自查**：提供任务、思路和英文词数统计，停笔后自动保存，也可手动保存或保存返回。对照一种参考写法与注意事项，完成恰好 3 项自查，再保存本次练习；之后可继续修订，修改文字后需重新自查。草稿与最近完成自查的文本分别保留
- **词数与结果有明确含义**：四级写作题目目标 120–180 词，六级 150–200 词；翻译的英文词数范围仅用于参考篇幅。最低输入量只是练习保存门槛，不是考试合格线。自查完成不代表内容已由系统评阅，不生成作文、翻译或总分
- **按记录推荐下一步**：先处理阅读待订正，再续写未完成或修订草稿，然后补未完成专项；全部完成后可重访较早的练习。计划日期用于提供阶段建议，不预测是否能过级

CET 原创阅读、写作与翻译档案独立存储，不发放 XP、金币，也不改动词汇 FSRS；完成数量表示练习记录。听力入口连接目标级别的原创短练，完整真题练习使用「近年真题」中的原卷、录音与独立档案。

### 日常加练：英语情景冒险

今日页内置 **9 个原创场景、3 个章节、27 道题**，不需要额外下载词书，所有场景可自由进入。每章按 A2、B1、B2 递进：

| 章节 | A2：读懂安排 | B1：理解原因 | B2：判断与表达 |
|:---|:---|:---|:---|
| 校园 | 给讨论找个位置 | 问卷先试一次 | 两个数字为何不同 |
| 城市旅行 | 周一改走哪条路 | 晚到也能入住 | 给河岸留一点空间 |
| 工作观点 | 会议前的十五分钟 | 先说清楚再交付 | 怎样衡量远程试行 |

- **先读故事，再作选择**：每场 4 轮中英对话，英文正文 50-110 词；中文提示由你按需展开，答题时随时能回看原文，没有倒计时
- **每场 3 题、每题 4 选 1**：分别练语境理解、推断和得体表达。选完立刻显示正确答案与中文解析，说明线索在哪里、为什么这样回应
- **一场一枚印章，最多三颗星**：单次答对 2/3 题即可收集该场景印章，星级按最佳单次成绩保留。冒险护照显示 9 枚印章与 27 星的收集进度
- **重玩能补齐遗漏**：每道题首次答对获得 **3 XP、1 金币**。首次没答对的题，重玩答对时可补领；已经领过的题不重复发奖。奖励随完整交卷保存，退出未交卷的练习需重新开始
- **学完带走 4 个表达**：结果页提供关键词与释义，也能回看本场三道题的答案和解析

情景练习独立记录星级、印章与真实用时，不改动单词的新词量、正确率或 FSRS 复习状态。

### 表达工坊：换个情境，自己说一句

**18 道原创迁移短语题**与 9 个冒险场景对应，每场 2 句。你会遇到新的预约、问路、协作等交际目的，在完整英文句子的一个空白中主动输入 **1–5 个英文词**。

- **先回想，再看帮助**：可以主动展开中文提示或查看参考；提交后展示参考句、常见接受变体和中文解析。界面区分「独立想起」与借助提示或参考完成
- **每题提交即保存**：进度与奖励随单题提交持久化，退出后已经提交的练习保留；尚未提交的输入不算完成
- **短轮回想**：到期队列每轮最多 5 句；全部 18 句始终可以按场景自由选择，不以完成冒险或等级作为门槛
- **按自然日安排复习**：首次或到期练习无提示正确后，间隔依次为 **1、3、7、14、30 天**，之后保持 30 天；到期练习使用提示、参考或答错时，回到明天再练。提前练习和同日重练保留原调度
- **奖励可回想的成长**：首次或到期练习无提示正确，获得 **3 XP、1 金币**；同题同日不重复领奖，提前练习也不重复发奖。独立完成日用来记录跨日找回记忆

答案依据题目明确列出的短语及变体匹配，容忍大小写、空格和句末标点差异。这是固定短语提取练习，不提供自由口语或作文评分；未匹配的写法不代表在所有语境中都错误。表达调度与词汇 FSRS 独立，不改变单词掌握状态或词汇正确率，无新增依赖。

### 听力

**四种题型**，都只针对一个考点，答完立刻知道错在哪：

| 题型 | 玩法 |
|:---|:---|
| 选词填空 | 听句子，从 4 个词里选出被挖掉的那个（最常用） |
| 听音选义 | 听句子，选出它的中文意思 |
| 词序排列 | 听句子，把打乱的词块排回正确顺序 |
| 整句听写 | 默认关闭。一句话十几词，错一个就全错，反馈不聚焦 |

> 早期版本只有整句默写，那是最劝退的练法。现在默认轮换前三种。

**原创听力短练**按主题组织，默认显示备考目标对应级别，也可页内切换四级或六级方向：

| 主题 | 方向 | 范围 |
|:---|:---|:---|
| 校园与科技 | CET-4 | 3 段材料、7–8 题短练 |
| 健康与环境 | CET-4 | 3 段材料、7–8 题短练 |
| 科技与职场 | CET-6 | 3 段材料、7–8 题短练 |
| 能源与工作生活 | CET-6 | 3 段材料、7–8 题短练 |

- **连续短练**：同主题材料连续作答，也可只练一段；材料 1/2/3 的顺序不对应官方考试分区
- 四选一 + 每题解析（为什么选这个、考点在哪）
- 同一段材料连答数题，换段自动朗读新材料，支持重听和调速
- 答完显示本次正确率与本轮错题回顾，可「再练一次」；离开后不保存逐题作答历史，听力复盘范围与持久保存的阅读档案不同
- 装了英语语音包后由 TTS 朗读（长材料自动分段，避免被浏览器截断）

这些材料由项目原创，不使用真实年份场次命名；未按官方整卷题量、播放流程、难度或分值校准，本次正确率不换算四六级分数。完整真题录音可从今日页「近年真题」查看或导入本机练习。

**10 篇内置材料**（校园、科技、环境、健康、文化、旅行、工作、教育、科学、社会），每篇 7 句，使用原创脚本和系统合成语音，每句配中文对照。离线发声取决于本机英语语音包是否可用。

**关于发音**：原创短练和句子练习靠浏览器语音合成朗读，需要系统装有英语语音包。若系统只有中文语音，应用会在听力页明确提示安装方法。近年真题使用来源录音或本机音频文件播放，不依赖系统英语语音包。

Windows：设置 → 时间和语言 → 语音 → 添加英语
macOS：系统设置 → 辅助功能 → 朗读内容 → 下载英语语音

### 词汇地图（闯关式）

单词页「地图」不是列表，而是一条**左右交错的闯关路线**：

- 每个节点是一关（一个单元），点亮=可进入，灰色=未下载（点击即下载）
- 金色呼吸的节点是你现在的位置，吉祥物会站在上面
- 每 5 关是一个 **BOSS 关**（奖杯图标）
- **点击已点亮的关卡直接开打**：该单元的到期复习 + 新词，打完这一关看进度

### 战斗舞台

背单词的舞台是「勇者 vs 词怪」的对战场景，攻击方向明确：

- 左侧是我的勇者（随词汇积累阶段进化），右侧是词怪（难度权重越高越大，BOSS 有皇冠）
- 答对：勇者向前突进 → 斩击光扫过 → 词怪碎裂；答错：词怪反扑 + 屏幕震动 + 红色受击边缘
- 连击 5 起火焰标记、连击 8 起屏幕边缘光晕；经验/伤害数字从词怪身上飘出

在设置里可随时切换主学词书，已有本地内容可直接切换，缺失内容显示下载进度。词书页按「**当前主学 → 已下载 → 可扩展**」分组排列，一眼看清哪些能直接学、哪些要下载。

### 成就馆：68 枚学习足迹，6 个方向

成就围绕**坚持、词汇、复习、拼写、听力、运用**六个方向组织，记录实际学习成果：回来练习、掌握更多词、找回曾经遗忘的词、拼得出来、听懂句子，以及读懂原创情景。本轮增加「自己说一句」「六句随身带」「表达行囊」「隔日仍记得」4 枚表达成就，分别记录不同短语的独立提取与跨日回想。

- **筛选与进度**：「全部 / 接近达成 / 已解锁」结合学习方向筛选，显示当前进度、目标与尚需完成的量，每次先展示 12 枚，再按需展开
- **追踪一个目标**：选择一枚公开成就后，成就馆与今日页共同展示；没有手动选择时，自动推荐最接近达成的公开成就。追踪偏好保存在当前浏览器
- **看见最近的积累**：展示最近点亮的成就与日期。达成条件自动解锁并发放固定金币，每枚仅奖励一次
- **保留探索感**：5 枚隐藏成就不提前展示名称和条件，也不进入推荐或追踪，解锁后才揭晓

当前条件奖励持续练习、正确作答与跨日找回记忆；不以答错次数、熬夜或花光金币作为新奖励目标。旧版已解锁的记录继续保留。

### 游戏化（M2 部分）

- **双轨成长**：经验等级与词汇积累阶段
  - 词卡积累按掌握词的难度权重汇总，阶段绑定历史峰值，**只升不降**；结果用于应用内成长展示
- **7 个积累阶段**：名称与门槛见上表，不推导英语测评等级
- **68 枚成就、6 个学习方向**，可筛选与追踪目标，达成自动解锁并发金币；5 枚隐藏成就保留发现的惊喜

- **表达与回想**：18 道迁移短语题，每轮最多 5 句到期回想；独立完成与跨日记忆带来明确的成长记录
- **打卡与安全网**：断签回退到最近 7 天整数档位（23→21），连续 7 天赠冻结券

### 听力（M1.5 核心 + 部分 M3）

- **原创主题短练**：按四级/六级方向筛选，每组 3 段材料、7–8 题，可连续练或单练一段；结果页仅回顾本轮，逐题记录不持久保存
- **句子练习**：10 篇原创短文，三种模式轮换：
  - 选词填空：句子挖空保留首字母，选出目标词
  - 听音选义：选中文意思
  - 词序排列：把打乱的词块排回正确顺序
  - 整句听写默认关闭（一句话十几词，错一个全错，反馈不聚焦）
- 单句循环、可选变速
- 全部内容内置，无需导入、无服务器成本

### 离线与 PWA

- Workbox 预缓存 App Shell，词库与音频使用运行时缓存；实际体积以当前构建输出为准
- **iOS 安装引导**：未安装到主屏时展示提示条，提醒用户安装并备份本地记录
- Service Worker prompt-based 更新，绝不在学习中强制刷新
- 数据备份导出**与导入合并**：schema 7 包含冒险进度、表达调度与奖励凭据、`cetPractice` 专项档案、`cetPapers` 真题档案及导入文件；音频和文档合计超过 100MB 时跳过超额附件并提示。复习日志取并集并重放 FSRS，同时恢复词书归属、库存及任务领奖状态，兼容缺少新增表的旧备份

- **单轮题量上限 24 题**：复习优先，剩余名额给新词。学完一轮可再来一轮，避免一次 36 题让人放弃

### 视觉：4 种风格 × 8 个配色选项

风格决定形状与字体，配色决定颜色，两者自由组合：

| 风格 | 形状 | 字体 |
|:---|:---|:---|
| 像素复古 | 直角、硬阴影 | 像素字体 |
| 现代极简 | 圆角 12px、柔和阴影 | 系统无衬线 |
| 护眼纸墨 | 细边框、无阴影 | 系统无衬线 |
| 暗夜专注 | 弱边框、靠留白分层 | 系统无衬线 |

配色：**星夜（默认，深蓝黑+金）** / GameBoy 绿 / 午夜霓虹 / 日落 / 传说金 / 深林 / 晨光米白（浅色）/ **自定义色相**。

**自定义色相**：拖动滑块选一个颜色，整套界面跟着变。全色相的对比度经过验证（副文字 ≥7.4:1、强调色 ≥5.9:1），绿（正确）红（错误）是语义色不跟随变化。附 6 个预设：琥珀、薄荷、湖蓝、鸢尾紫、山茶粉、绯红。

不喜欢像素风也没关系：换成「现代极简 + 晨光米白」就是一套干净的浅色效率工具。

三条硬约束，详见 [DESIGN.md](./DESIGN.md)：

- **字号只走 12 的整数倍**（12/24/36/48）。Fusion Pixel 是 100 units/px 的 12px 原生网格字体，非整数倍会糊
- **对比度 ≥ 4.5:1**。四套主题的副文字实测 5.08–6.55，全部通过 WCAG AA
- **图标是画的，不是 emoji**。22 处 emoji 全部替换为 16×16 像素 SVG

其他：Fusion Pixel 按实际字符集子集化 **923KB → 115KB**；吉祥物随段位进化（蛋 → 幼年体 → … → 传说形态），怪物难度对应词频；CRT 扫描线可关，遵守 `prefers-reduced-motion`。

### 数据模型

```
words(id, word, phonetic, definition, bookId, bookUnits?, freqRank, difficultyWeight, unitId)
stats(wordId, fsrs{stability,difficulty,due,reps,lapses,learning_steps?}, state, mistakeCount)
reviewLogs(id, wordId, rating, reviewedAt, deviceId, elapsedMs, mode, correct)  ← append-only
dailyLogs(date, newLearned, reviewsDone, xp, coinsEarned, effectiveDay, studySeconds)
profile(level, xp, power, powerPeak, rankId, coins, streak, freezes, ...)
achievements(id, unlockedAt) · quests(date, questIds, progress, chestOpened)
adventures(sceneId, bestScore, attempts, correctQuestionIds, firstPlayedAt, lastPlayedAt, completedAt?)
expressions(id, sceneId, attempts, firstPracticedAt, lastPracticedAt, dueAt, stage, lastScheduledDate,
            independentDays, rewardedDates, lastOutcome)
cetPractice(id, examType, kind, draft, updatedAt, firstSubmittedAt?, firstAnswers?, latestAnswers?,
            submittedText?, submittedAt?, checks?, completedAt?, attempts)
cetPapers(id, sourceId, variant, createdAt, updatedAt, answers[55], answerKey[55], writingDraft,
          translationDraft, notes, elapsedSeconds, files, firstSubmission?, latestSubmission?)
```

**review_log 是核心资产**：合并时取并集去重，FSRS 状态由日志重放推导。刚提交的日志允许手动修正评级并重放；不采用整条学习状态最后写入覆盖。

数据库当前为 **schema 7**，保留 `adventures`、`expressions`、`cetPractice` 并增加 `cetPapers`。冒险的 `bestScore` 保存最佳单次答对题数，`correctQuestionIds` 保存跨次首次答对题目集合，并作为防重复领奖凭据；备份合并不把多个低分轮次拼成满星成绩。

`expressions` 以题目 id 为主键，记录所属场景、尝试次数、首次/最近练习时间、到期时间、间隔阶段、最近调度日期、独立完成日期集合、已奖励日期集合与末次表现（`independent` / `assisted` / `retry`）。备份采用较新调度，同日冲突取更早到期与较低阶段，日期凭据取并集、次数取较大快照；合并本身不重新发奖，旧备份缺省该表仍兼容。

`cetPractice` 保存独立专项档案。阅读保留首次完整提交和最新完整订正；写译保留最新草稿与最近一次完成自查的文本。合并分别比较草稿更新、最近提交、首次阅读时间，尝试次数取较大值，首次完成时间保留最早值；旧备份缺少该表时兼容。CET 档案不混入词汇复习日志或游戏奖励。

`cetPapers` 保存高校资料对应的本机练习档案。首次/最近核对各自包含答案、参考答案与时间快照；附件字节保存在 `media`，档案只存引用。备份导入前校验来源、55 题选项、提交时间和附件关联，分别合并草稿与核对记录，并保护本机唯一文件。`elapsedSeconds` 为预留数据字段，当前界面不提供整卷计时考试。

## 已知限制

- **个性化 FSRS 参数优化未实现**：优化器是原生模块，浏览器跑不了；MVP 用官方默认参数
- **音频包未生成**：单词发音走 Web Speech API（音色随系统），Opus 音频包方案（Piper/Kokoro）待接入
- **听力材料库元数据存在 localStorage**：音频本身在 IndexedDB，元数据量大时需迁移
- **云同步未实现**（M3）：当前只有本地 JSON 导出 + 导入合并，需要用户自己搬运文件
- **原创专项内容量有限**：阅读目前只覆盖仔细阅读短练；写译依赖学习者参考自查，没有自动阅卷、完整模拟考试、分数预测或过级保证
- **真题为资料入口与本机练习档案**：未内置整卷题库，不自动解析 PDF 或认证参考答案；原站链接需联网且可能变化。当前每期仅收录来源第 1 套，练习前需核对套号与题目；没有整卷计时或自动写译评分
- **原创听力逐题历史不持久保存**：错题回顾仅限当前一轮，离开后不能恢复；阅读专项与近年真题答题卡可持久复盘
- **TTS 分级材料、跟读、动态复现**（M3）未实现
- 未打包 Capacitor APK（M1 出口之一）

## 已修复的关键缺陷（历史记录）

以下保留开发过程中已修复问题的历史背景；其中的成就数量与旧版行为不代表当前产品规则，现行规则以上文说明为准。

| 缺陷 | 后果 | 修复 |
|:---|:---|:---|
| 听力音频表未在 schema 声明 | 导入的音频永远存不回来，静默丢失 | schema 升到 v2 补上 `media` 表 |
| 手动改评级重复提交 | 同一题写两条日志、重复加 XP、FSRS 推进两次 | 改为 `overrideRating` 改写日志后重放 |
| 听力 XP 只写 daily 不写 profile | 听力练得再多，等级永远不涨 | 统一走 `awardRewards` 同时更新两处 |
| `recordCombo` 从未调用 | 3 枚连击成就永远无法解锁 | 在答题流程里接入 |
| 听力不检查成就 | 8 枚听力成就永远无法解锁 | 答题后调用 `checkAchievements` |
| 宝箱碎片只弹提示不发放 | 「每 5 个宝箱得碎片」是空话 | 写入 `themeFragments` 并开放碎片兑换 |
| 听力不更新 studySeconds | 只听力的日子不算有效学习日 | 同时累加时长与句数 |
| 快速连点重复提交 | 一次作答写多条日志 | 加同步 `submittingRef` 锁 |
| 单轮题量无上限 | 复习堆积时一轮 36 题，劝退 | 上限 24 题，剩余提示再来一轮 |
| `dormancy` 从不置 true | 休眠机制形同虚设 | 启动时按 30 天未学判定 |
| `listen-1` 任务语义错位 | 「完成 1 段」实际要听满 60 秒 | 改为「精听 1 分钟」，目标 60 秒 |
| 词库释义重复拼接 | 「能力, 才干能力, 才能」 | 领域标记行整行丢弃 + 包含关系去重 |
