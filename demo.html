能力

做了什么

  • FSRS 间隔重复

    ts-fsrs 官方默认参数，四档评级由作答正确性与用时自动推导，也可手动纠正。

  • 六种题型

    看词选义 / 看义选词 / 拼写 / 听音辨义 / 听音拼写。复习轮里拼写类占一半以上。

  • 六本词书

    四级/六级各分核心与全本，另有考研核心、雅思核心。ECDICT（MIT）同源，清洗释义、归一化 IPA。

  • 词根拆解

    611 条词根词缀，448 条带本地例词，可拆解 1506 个单词。

  • 听力四题型

    选词填空 / 听音选义 / 词序排列 / 整句听写（可选）。10 篇内置原创材料 + 真题导入。

  • 电脑与手机都适配

    宽屏切侧边栏多列布局，窄屏底部导航单列。同一套代码，不用装两个版本。

  • 英语水平命名

    词芽 / 短语匠 / 段落读者 / 论说文手 / 学术阅览者 / 语感行家 / 词源考据者，每个都对应具体能做的事。

  • 多套视觉风格

    像素复古 / 现代极简 / 护眼纸墨 / 暗夜专注，配 6 种配色，自由组合。

  • 离线优先

    Workbox 预缓存 500KB，词库按需缓存。断网刷新、断网答题全部可用。
