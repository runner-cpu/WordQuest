# 近年四六级真题资料来源核对

核对日期：2026-10-30（用户环境日期）。仅保存短标题、来源和附件元数据，不下载或内置整卷正文。资料目录位于 `src/data/cetPaperSources.ts`。

## 范围与性质

- 14 条目录：2023-06、2023-12、2024-06、2024-12、2025-06、2025-12、2026-06，四级和六级各 7 条，均为来源标注的第 1 套。
- 不收录尚未举行的 2026-12。
- 南京大学 eol 平台是高校托管来源；页面提供试题、答案及听力，但不能据域名认定为教育考试院官方原卷或官方答案。部分 PDF 明示为个人制作、学习交流，目录统一标为“真题资料／整理版”。只核对年月、级别、套号及文件入口，未将整卷逐题与考试院原稿比对。
- 新疆第二医学院语言文化部资料页标题为“四、六级真题（23-6,23-12,24-6）”，发布日期为 2024-12-16；未明确说明是否官方原卷、回忆整理，也未单列答案附件，目录保留这项不确定性。
- “第 1 套”是来源整理编号，不认定它与其他出版社的同名套号完全对应。

## 直接核对的方法与结果

1. 用 web 搜索和打开南京大学两级目录、各单套资料页，核对页面标题与下载链接；不依赖搜索摘要建立条目。
2. 随后用 Windows `curl.exe --http1.1` 对下列 10 个南京大学资料页实际 GET，均得到 HTTP 200；从实际 HTML 的 `<a href>` 取得文件名。
3. 对南京大学 30 个附件逐一 HEAD，均返回 HTTP 200。20 个 PDF 返回 `application/pdf`，10 个 MP3 返回 `audio/mpeg`。因此资料数组的附件地址来自已验证链接，不按年月拼猜文件名。web 阅读器个别 PDF 读取超时，用直接 HTTP 头检查确认链接存在；这不代表对所有 PDF 做了全文校勘。
4. 用 `Invoke-WebRequest` 对新疆第二医学院资料页实际 GET，HTTP 200，直接核对 HTML 标题、发布日期和全部附件标题及 ID。该站附件入口的响应为验证码网页（`text/html`），标题“附件下载”，显示“请输入验证码下载附件”；没有绕过验证码，目录提示用户在学校网页手动下载。
5. 没有下载音频或整卷到项目；项目仅存元数据。链接状态为本次核对结果，不保证远端长期可用。
